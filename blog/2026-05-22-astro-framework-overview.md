## Что такое Astro?

**Astro** — это современный статический генератор сайтов (SSG) и фреймворк для создания быстрых веб-приложений с минимальным JavaScript в браузере.

Официальный девиз: *"Build faster websites with less client-side JavaScript"* (Создавай быстрые сайты с меньшим количеством клиентского JavaScript).

### Ключевые особенности:

- **Zero JS by default** — по умолчанию на страницы не отправляется JavaScript
- **Island Architecture** — интерактивные компоненты ("острова") отправляются отдельно
- **Framework Agnostic** — поддерживает React, Vue, Svelte, Solid и другие фреймворки одновременно
- **Static First** — оптимизирован для генерации статики с опцией SSR
- **Конвертация на лету** — автоматически конвертирует UI компоненты в HTML статику

## Как это работает?

### 1. Архитектура остров (Island Architecture)

```
┌─────────────────────────────────────────┐
│         HTML Статическая страница        │
│  ┌──────────────────────────────────┐   │
│  │  React компонент (интерактивный)  │   │
│  │         ("остров")                │   │
│  └──────────────────────────────────┘   │
│  ┌──────────────────────────────────┐   │
│  │  Vue компонент (интерактивный)    │   │
│  │         ("остров")                │   │
│  └──────────────────────────────────┘   │
└─────────────────────────────────────────┘
```

Страница отправляется как HTML, а компоненты, которым нужна интерактивность, гидрируются отдельно.

### 2. Процесс сборки

1. **Написание кода** — создаёшь `.astro` файлы, React/Vue компоненты
2. **Статическая генерация** — `astro build` преобразует всё в HTML
3. **Отправка на сервер** — готовые HTML файлы + JS только где надо
4. **Гидрация** — интерактивные компоненты инициализируются в браузере

### 3. `.astro` файлы

```astro
---
// Серверный код (Node.js)
import { getPostList } from '../lib/posts';
const posts = await getPostList();
---

<!-- HTML шаблон -->
<div class="posts">
  {posts.map(post => (
    <article>
      <h2>{post.title}</h2>
      <p>{post.excerpt}</p>
      <a href={post.url}>Читать далее →</a>
    </article>
  ))}
</div>

<style>
  .posts {
    display: grid;
    gap: 2rem;
  }
</style>
```

## Производительность

### Метрики Core Web Vitals

| Метрика | Астрический сайт | Среднее значение |
|---------|------------------|------------------|
| **LCP** (Largest Contentful Paint) | 1.2s | 2.5s |
| **FID** (First Input Delay) | 45ms | 100ms |
| **CLS** (Cumulative Layout Shift) | 0.05 | 0.1 |
| **Размер JS бандла** | 15-50KB | 100-300KB |

Astro — это **мощный инструмент для специфических задач**, а не universal solution. Он переворачивает мышление о том, как должны работать веб-сайты в эпоху требовательности к производительности.
