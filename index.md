### В процессе публикации я столкнулся со следующими проблемами:
1. Подключение темы.
> Просто напиши в `_config` если хочешь работающую не глючную версию Minima:
```yml
remote_theme: "jekyll/minima@1e8a445"
# без отступа слева
```
2. Настройка Theme : Minima
> Напиши в точности так и не думай :
```yml
title: Название сайта - будет на header и в <title>
author:
  name: твоё displayed name
  email: твой емайл

description: >
  эта строка будет в мета тегах и в превью ссылки в телеграм и вотсапп а так же в других соцсетях. Можно 
  делать перенос Shift+Enter так как есть в начале галка вправо

remote_theme: "jekyll/minima@1e8a445"

plugins:
  - jekyll-feed
  - jekyll-seo-tag

sass:
  quiet_deps: true
  silence_deprecations: [import]

```
3. Настройка skin для темы.
> В настройках `minima:` НИГДЕ не написано что `skin: "dark"` именнно в кавычках работает а без кавычек - нет. Видимо это уже специфика либо jekyll либо GItHub
```yaml
minima:
  skin: "dark"
```
4. Настройка header и nav-menu
> Так же нигде не написано что рабочий вариант - без отступа вне блока `minima:`
```yaml
# без отступа слева !!!
header_pages:
  - pages/notes.md
  - pages/about.md
  - pages/contacts.md
  - index.md
```
Настройка для `minima:` через `nav_pages:` у меня никак ни в каких вариантах так и не заработала
5. Настройка footer  
Футер адекватно заработал только после подключения через remote-theme как написано в пункте №1
